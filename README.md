# 🎮 Snowborderer
Slide your way to the finish line as a snowborderer in this 3D game made in Unity.
<img width="1523" height="709" alt="Snowborderer" src="https://github.com/user-attachments/assets/9811cd01-e623-46bc-9268-d787c2e61148" />

## 🛠️ Technical details
* **Slideing system** -> it's made with the Surface Editor 2D from Unity by adding some speed and force
* **Crushing system** -> when you crush with the ground, you lose and the game resets
* **Winning system** -> pass the finish line and you win
* **Rotating system** -> when the snowborderer is in air, you can rotate him to avoid crushing with the ground
* !! I don't own the assets

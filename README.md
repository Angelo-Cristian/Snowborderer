# 🎮 Snowboarder
Slide your way to the finish line as a snowboarder in this 3D game made in Unity.
<img width="1523" height="709" alt="Snowboarder" src="https://github.com/user-attachments/assets/9811cd01-e623-46bc-9268-d787c2e61148" />

---

## 🛠️ Technical details
* **Sliding system** -> It is made using the Surface Effector 2D in Unity by adding surface speed and force.
* **Crashing system** -> When your head crashes into the ground, you lose and the level resets.
* **Winning system** -> Pass the finish line and you win.
* **Rotating system** -> When the snowboarder is in mid-air, you can rotate the character to stick the landing and avoid crashing.
* ⚠️ *Note: I do not own the art/UI assets used in this project.*
